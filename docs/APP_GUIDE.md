# 桌面 App 使用指南

本文档详细介绍 LitSSH 桌面管理端的页面、会话、数据源、拓扑、AI 助手和设置能力。截图与精简介绍见根目录 README。

WPF 桌面管理端，主界面为**左侧图标导航栏 + 右侧页面**：顶部依次为 **主页 / AI 运维助手 / 通知中心 / SSH 会话管理 / SSH 服务器管理 / 数据源管理 / 应用管理 / 远程桌面 / Jenkins / Kubernetes / 工具箱**（页面形式，独立窗口入口除外）；分割线以下为 **资产拓扑 / 审计日志**（独立非模态窗口，不置顶，可同时操作主界面）；**最下方为「设置」**（常规 / 终端 / 命令片段 / 外观 / 安全设置 / 工具分组 / 导入导出 / 存储维护 / 桌面宠物 / 关于）。**AI 运维助手**（内置大模型运维智能体）是左侧 AI 导航的常驻页面，可从主页快捷入口 / AI 快捷提问进入，也可弹出为独立窗口（任务不中断，可收回主界面）。

## 主页看板

**快捷入口**（SSH 会话管理 / 资产拓扑 / 审计日志 / AI 运维助手）、**数据看板**（SSH 服务器总数与禁用数、数据源数、应用数、端口转发规则、远程桌面、同步任务、触发事件；点卡片可跳到对应管理页）、**AI 快捷提问**（输入问题或添加附件后发送，会填入 AI 运维助手输入区）。

## SSH 服务器管理与会话

**SSH 服务器管理**页提供服务器表格：顶部仅 **添加 / 刷新**，其余操作走条目**右键菜单**（连接 / 编辑 / 采集快照 / 快照历史 / 删除），**双击**行打开编辑窗口，支持列排序。右键**「打开终端（交互式）」**打开独立的 **「SSH 会话管理」多标签窗口**（非模态、不置顶；同一服务器最多 4 个终端，标题自动带序号）。**终端标签**为交互式 PTY shell（自绘 VT100/ANSI，支持 `vim`/`top`/`htop`/`less`、颜色、滚动回看、窗口自适应），且**左侧分栏内嵌服务器文件可视化**（SFTP：目录导航、上传 / 下载、新建文件夹、重命名、删除，双击文件下载并打开）。

**会话可分离为独立窗口**：在**标签布局**拖动标签、在**平铺（卡片）布局**拖动卡片头把手，**拖离窗口松手**即把该会话弹出为一个**独立、紧凑、可缩放、可自由摆放**的窗口（位置/尺寸按会话记忆）；独立窗口右上角有「收回」（送回主窗口）与「✕ 关闭会话」，标签/卡片右键也有「分离为独立窗口」。终端连接状态由会话 VM 持有，分离/收回**不重连、不断开**。

**服务器连接增强**：服务器可配置 **跳板机（ProxyJump，经另一台已配置服务器中转）**、**生成 SSH 密钥**（ed25519 / rsa(4096)，优先系统 `ssh-keygen`、缺失回退内置 RSA；生成后展示 **OpenSSH 公钥**一键复制到目标机 `~/.ssh/authorized_keys`）、以及**凭据轮换提醒**（凭据变更自动刷新更新时间、超期在编辑窗口提示）。跳板机在 **SSH 连接工厂统一生效**，故**终端（含文件管理）/ SFTP / 命令 / 同步 / 拓扑发现 / MCP 工具（含连接复用）/ 数据源隧道 / 端口转发**均自动支持（仅**单级**跳板；跳板机不能与目标同 Host、不能选自身；`litssh` CLI 与 rsync 源↔目标直连路径亦带 `-J`）。

**批量执行 / 快速命令**：SSH 服务器管理页 **「批量执行」** 打开多机并行执行窗口，内置一排**快速命令**（一键巡检、磁盘 / inode / 内存 / 占用端口 / CPU·内存 Top / 大目录 / 最近日志 / Docker 容器 / 网络地址）与 **「一键巡检」**；写操作以 `⚠` 标注并在执行前**弹确认**。

**会话录像 / 回放**：交互式终端会话（`terminal.recordSessions` 默认开）以 **asciicast v2（`.cast`）** 记录输入/输出的**时间戳**；`.log/.cast` 落盘前统一脱敏密码/token 等敏感内容。 「会话日志」窗口提供**播放 / 暂停 / 重开 / 倍速（1/2/4/8x）**回放（去 ANSI 文本渲染），并保留原 `.log` 纯文本；录制过程中也可打开查看，刷新列表即可看到新增内容。

**日志文件「终端操作」**：在交互式终端左侧远程文件面板选中文件，右键 **「终端操作」** 可把命令直接发送到右侧终端（仅在终端已连接、回到 shell 提示符且未运行全屏程序时发送，否则提示原因）。内置 **最近 1 小时 / 指定时间范围搜索、`tail -f` 实时跟踪、最新 N 条、错误 / 异常过滤、关键字上下文与计数、实时过滤、`less` 末尾打开（`q` 退出）**，以及 **「筛选并保存到文件…」日志切片**（按关键字 / 时间 / 扫描行数过滤后写入远端文件，默认同目录 `*.slice-yyyyMMdd-HHmmss.log`，完成后刷新文件列表即可下载；输出路径须为绝对路径且不能与源文件相同）。时间过滤支持行首 ISO、nginx 错误日志 `yyyy/MM/dd` 与 nginx/Apache 访问日志 `[dd/Mon/yyyy:HH:mm:ss`；syslog 建议改用关键字 / 最新 N 条。发送成功后自动把键盘焦点移回终端；文件面板底部状态固定单行省略、悬浮显示完整内容，避免挤压列表。

**跨机复制（源→目标，走服务器间内网通道）**：两个入口——① **SSH 服务器管理**条目右键 **「远程互传（服务器↔服务器）…」**（左右两侧均为可切换的服务器文件浏览器，左侧多选源文件）；② 会话的远程文件面板**多选**后右键 **「复制到远程服务器…」**，弹窗左侧为待复制列表、右侧选择**其它服务器**（可切换 **主机地址 / 内网地址**）并浏览目标目录，确认后由**源服务器直接推送**到目标（优先 `rsync`，退化 `tar | ssh`，可 `-z` 压缩），**数据不经本机磁盘**、利用服务器间内网高速通道；认证优先源机免密，其次 `sshpass` + 目标密码（密码经 stdin 写入源机 0600 临时文件，不进命令行）；若源机**缺 `sshpass`** 会**弹出安装引导框**（按发行版给出 `apt-get`/`yum`(含 EPEL)/`dnf`/`zypper`/`pacman`/`apk` 命令，可复制），安装后点「已安装，重试」；直连不可用时默认报错，勾选「直连失败时询问是否内存中转」后会**弹窗让用户确认**是否改用**经本机内存中转**（不落盘）；传输完成后**自动刷新目标文件列表**。跨机复制使用的**内网地址 / 内网端口**在服务器配置中可选填写。

**文件 / 文件夹同步（单向）**：SSH 服务器管理页 **「文件/文件夹同步」** 按钮 → 独立窗口创建多个任务，方向支持 **本地→远程 / 远程→本地 / 远程→远程**（仅单向）；默认**只新增/更新、不删除**，「镜像删除目标端多余文件」为**显式选项**；**「测试」为可选自检**（实际传一个探针文件验证连通与认证，不再作为保存前置）；调度支持 **固定间隔 / 每周固定时刻（多选周几） / 每月固定（多选日期 1-28）**；失败按**指数退避重试（≤5 次）**；**仅 App 运行期间执行**。本地↔远程用自研 SFTP 比对/传输引擎（`size + mtime`，临时文件 + rename 原子落盘）；远程↔远程走**服务器端 `rsync` 直连**（不经本机，测试前校验两端是否安装 rsync，缺失给出该端发行版安装命令）。任务可设 **「仅同步 / 排除」文件过滤**（glob，支持 `*` `?`）与 **「使用内网地址」**（远程↔远程，经目标内网地址连接）。**测试 / 保存 / 立即运行**的结果以**模态弹窗**展示（正文可复制），失败时给出**源机免密配置命令**（`ssh-keygen` / `ssh-copy-id` / 验证命令）或 sshpass+密码替代路径。路径支持**「选择文件夹」**（本地）与**「浏览远程」**（服务器目录回填）。

**触发事件（git / webhook / 备份）**：SSH 服务器管理页 **「触发事件」** 按钮（或主页「触发事件」看板卡片）→ 独立窗口创建多个触发事件，可对**本机或远程服务器**按顺序执行一条**动作流水线**：**Git 提交推送**（`status`→`add -A`→`commit`→`push`，无变更自动跳过）、**Webhook 通知**（通用 JSON / 钉钉 / 企业微信 / 飞书；`{{变量}}` 模板 + 钉钉/飞书加签，密钥 DPAPI 加密）、**目录备份**（Zip / TarGz 打包到输出目录，可「保留最近 N 份」自动清理最旧；远程优先 `tar`、缺失回退 `zip`）、**数据库备份**（MySQL / PostgreSQL，**整库或指定表**，产物 SQL 转储、可选 gzip 压缩为 `.sql.gz`，可「保留最近 N 份」；输出目录随执行目标：目标=本机则在本机执行落盘（需本机 `mysqldump` / `pg_dump`，经 SSH 隧道的数据源自动建隧道，探测不到工具时退化为**托管流式导出**），目标=远程服务器则在服务器上执行并落盘到**服务器目录**（需服务器已装客户端工具且能访问该数据库）；受**全局备份并发数**约束，避免多任务同时 dump 压垮本机 / 目标）。**触发源**可叠加：**手动「立即执行」**、**定时**（固定间隔 / 每周 / 每月，复用同步调度模型）、**被同步任务「事件触发」**（在触发事件里勾选「允许被同步任务事件触发」，再到「文件/文件夹同步」任务末尾选择本事件及条件：**无条件触发** / **仅同步成功时触发**）。单步失败默认中断后续，可勾选**「失败后继续」**（如失败也要发通知）；失败按**指数退避重试（≤5 次）**；git、目录备份与数据库备份写入审计库；**仅 App 运行期间生效**。窗口内 **「总览」** 只读可视化每个触发事件的启用/目标/同步触发、**调度描述 + 下次运行 + 上次结果**与**动作流水线**（步骤卡片 → 箭头，标注失败中断/继续）。

**关闭主窗口**时可选**「最小化到托盘」**（后台继续运行，SSH 会话 / AI 任务不受影响；**已打开的独立窗口一并隐藏**，双击托盘图标恢复——**已启用应用锁时恢复前需先解锁**，恢复时先前隐藏的窗口一并显示；右键菜单可显示主界面 / 退出）或**「退出程序」**（**连同所有独立窗口一起退出**：AI 助手 / 审计日志 / 资产拓扑 / SSH 会话管理 / 远程桌面 / 同步 / 触发事件 / 设置等，不再残留）。

**采集快照**会连服务器采集整机态势（资源 / 端口进程服务 / 证书 / systemd 健康 / 安全巡检，同步、典型 10~30 秒，同一服务器同时只允许一个），完成后打开**快照历史窗口**：可切换服务器，左列历史列表 → 右侧查看该次快照的**采集维度概览 / 采集事件 / 原始数据**；窗口内 **「趋势图」** 用该服务器最近成功快照画 **内存% / 磁盘%(最大分区) / Swap% / 负载%(1m/核)** 折线（轻量自绘图，无第三方图表库）。

## 资源监控 / 计划任务 / Docker / 防火墙

- **资源监控与占用分析**：服务器右键「资源监控」查看 CPU / 内存 / 磁盘 / 负载、系统发行版与版本、内核；数据定时刷新。CPU、内存、磁盘各自提供「占用分析」和「AI 分析」：分析窗口分概览 / CPU / 内存 / 磁盘，展示采样使用率、负载/iowait/steal、Top 进程、内存/swap/OOM/PSI、挂载点/inode/只读、Top 目录/大文件/已删除未释放文件、journal/Docker/iostat，并尽量将 PID 归因到 systemd 服务或 Docker 容器；磁盘支持有超时和排除规则的深度扫描。AI 分析可只分析当前指标或整体资源，允许只读追溯进程、服务、容器、文件、日志和网络连接，不执行修改、清理、重启或终止进程。
- **计划任务**：服务器右键「计划任务」查看当前用户、`/etc/crontab`、`/etc/cron.d`、`cron.hourly/daily/weekly/monthly` 和 systemd timers；root / 其他用户 crontab 通过「加载提权任务」按需读取。cron 表达式解析为中文重复方式（如“工作日 02:30”“每月 1 日 00:00”），同时保留原始表达式和下次执行时间；自动识别命令引用的脚本并显示解释器、权限、属主、内容和语法检查。支持脚本内置编辑（LF、备份、写后校验）、暂停/启用（cron 注释标记、systemd stop/disable、目录脚本 chmod）、立即执行和审计；「发 AI 分析」可编辑提示词后发送，按当前任务或整体输出，并允许只读追溯脚本依赖、服务、容器、日志和网络连接。
- **Docker 查看/管理**：服务器右键打开 Docker 面板，查看容器列表、状态、CPU/内存/网络/磁盘、日志和 inspect 详情；支持启动 / 停止 / 重启 / 暂停 / 恢复容器（执行前确认并写审计）。无 `docker.sock` 权限时自动尝试已配置的 sudo/Su，仍失败则明确提示无权限。
- **系统防火墙**：服务器右键打开防火墙面板，自动识别 UFW / firewalld / nftables / iptables 及运行状态。UFW 支持入站/出站端口规则增删改，firewalld 支持默认区域入站端口/服务增删改，规则立即生效并持久化；表单按协议 / 端口 / 来源 / 策略 / 方向组织，支持多端口和端口范围。nftables / iptables 只读，并按表 / 链 / 规则结构化展示。修改前显示命令预览并自动备份，备份可一键恢复；SSH 端口规则禁止在面板中修改；界面提示 Docker 发布端口可能绕过防火墙。

## 数据源与应用管理

- **数据源管理**：维护 MySQL / PostgreSQL / Redis 等数据源；顶部 **添加 / 刷新**，条目**右键菜单**为 测试连接 / 编辑 / 删除，双击也可编辑（类型切换时自动带出默认端口 3306/5432/6379）；可设置**治理**项（只读、最大行数、超时、写审批策略）与 **TLS**（`sslMode`：`None` / `Preferred`（默认）/ `Required` / `VerifyCA` / `VerifyFull`；旧版 MySQL/MariaDB TLS 握手失败报 `SSL Authentication Error` 时选 `None`；MySQL 8 非 TLS 可开 `allowPublicKeyRetrieval`；`sslCaFile` 指定本地 PEM CA）。隧道下客户端连 `127.0.0.1`，`VerifyFull` 通常因主机名不匹配不可用，建议 `Required` 或 `VerifyCA`。密码仅本机 DPAPI 加密保存、不对 AI 开放。删除时会提示并级联清理引用它的关系。顶部 **「打开工作台」** 或右键 **「打开工作台（只读查询）」**（MySQL / PostgreSQL / Redis 可见，打开即定位到该数据源）进入**数据库工作台**：SQL 数据源支持对象浏览（库 → 表 → 列，含类型图标、选中对象面包屑与搜索匹配计数）、SQL 查询、表数据分页预览，Redis 支持 **键浏览**（分批 `SCAN` 时间预算续扫、键值有界读取、补全类型/TTL/大小、顶部 DB 切换、大结果集命令执行前警告）与命令输入；两者均有 **片段**（按「数据源 · 库」收藏、点击追加）、**结果复制**（复制单元格 / 整行 / 全部、双击查看完整内容）与 **导出 CSV**；顶部 **只读 / 写入模式**切换（默认只读，写入模式标题、SQL 框、执行按钮与结果区均以红/橙强区分）；写操作复用安全链（危险语句硬拦截 + **执行前预览确认**：展示 SQL 与预计影响行数/样本行 + 执行后成功失败弹窗提示 + 审计），只读数据源不可开启写入。
- **数据库用户管理**：数据源右键「用户管理」（MySQL / PostgreSQL）查看账号/角色、登录状态、密码状态和数据库/Schema/表权限矩阵；支持授权/撤权、修改密码、创建/删除用户或角色（高级），执行前显示 SQL 预览和权限差异并确认，变更前自动保存权限快照、支持快照回滚，密码脱敏，变更写审计；权限矩阵支持搜索、仅看变更、数据库/Schema 筛选和分页，并提示 MySQL 表级权限继承，支持对当前筛选表批量勾选/清空；当前连接账号保护，MySQL `*.*` 全局权限和 PostgreSQL `SUPERUSER` 不在普通页面开放，MySQL 除 information_schema 外的系统库可授权但会提示高风险；MySQL 可锁定/解锁账号、设置密码立即过期/取消过期，PostgreSQL 可切换 LOGIN/CREATEDB/CREATEROLE 且超级用户保护；PG 高级页可查看/授予/撤销角色成员关系，查看/添加/撤销默认权限，权限矩阵显示对象所有者，PG 权限为包含角色继承的有效权限；高级信息按需加载并合并查询以降低数据源限流概率，Redis 暂不支持。
- **应用管理**：维护 `app:` 应用节点（名称 / 类型 / 端口 / 主机 / 描述 / AssetKey / 别名）；**运行环境**可设 SSH 服务器、Docker 应用或独立环境，Docker 环境需填容器名或 Compose service（至少一个），拓扑据此推导 `runsOn/runsIn`。**URL 访问入口**支持多条，每条含 URL、角色（自动 / 公网入口 / 后端应用 / 内部访问）、优先级与备注；同一 URL 多后端视为负载均衡，供 `topology_query(action="resolve_url")` 解析。Docker 应用把类型填 `docker` 并填**容器名**（与 `docker ps` 的 NAMES 一致），AI 即可用 SSH 工具管理；顶部 **添加 / 刷新**，条目**右键菜单**为 编辑 / 删除，双击也可编辑。

## 远程桌面（RDP / VNC）

独立的**「远程桌面」**管理页（左侧导航 / 主页数据看板卡片进入）：可**添加、管理并连接** RDP / VNC 远程桌面。连接支持协议（RDP / VNC，切换时自动带出默认端口 3389 / 5900）、主机 / 端口、账号 / 密码（仅本机 **DPAPI 加密**保存，永不对 AI 开放）/ 域，**可经某台已配置的 SSH 服务器建立隧道**（复用端口转发服务，含 **ProxyJump** / 主机键策略 / 断线重连——可访问**只在堡垒机后可达的内网桌面**），以及全屏、自动填充凭据、**RDP 分辨率下拉预设**（自适应 / 1280×720 / 1600×900 / 1920×1080 / 2560×1440 / 3840×2160 / 自定义）、VNC 查看器路径（留空自动探测 TigerVNC / TightVNC / RealVNC / UltraVNC）、分组 / 标签 / 描述。每次连接**写入审计**。配置持久化到 `config.json` 的 `remoteDesktops`。

**连接方式**（管理页「连接」/ 双击 = 内嵌窗口）：

- **内嵌窗口（默认）**：多标签的「远程桌面」窗口（自绘顶部栏，标签样式与「SSH 会话管理」一致），标签内容常驻（切标签不重连），**标签可拖出分离为独立窗口 / 收回**（分离窗口自带「收回」按钮；标签右键亦可分离），关闭标签需二次确认。
  - **RDP**：用系统自带 **RDP ActiveX 控件**（`mstscax.dll`，经 `WindowsFormsHost` 承载）在窗口内渲染。
  - **VNC**：用 **WebView2** 承载随包分发的 **noVNC** 页面（`Assets/novnc/`，MPL-2.0），经本机回环的 WebSocket 桥（`/websockify`）连到目标 VNC（可经 SSH 隧道）。
- **外部客户端**：管理页「用外部客户端打开」——RDP 调用系统 `mstsc`（口令经 Windows 凭据管理器 `cmdkey` 暂存）、VNC 调用本机查看器；**查看器退出后自动拆除隧道**。

> 环境要求：RDP 依赖系统 RDP 组件（Windows 自带）；内嵌 VNC 依赖 **Microsoft Edge WebView2 运行时**（通常随 Edge/Windows 预装，缺失时给出安装提示）。后续计划：拓扑、`.rdp`/`.vnc` 导入导出、MCP 只读清单。

## Jenkins 多连接

左侧导航新增 **Jenkins** 页面，支持配置**任意数量**的 Jenkins 连接，不写死测试/生产两个：测试、预发布、生产、第三方公司、自定义环境都可以同时存在，同一环境类型也可以配置多个连接。每个连接独立保存地址、用户名、API Token（DPAPI 加密）、超时、TLS 策略、只读模式、操作确认策略，以及可选的 **SSH 隧道服务器**。

- **View 分组**：读取 Jenkins View，可在左侧切换 View；View 内任务与根任务同样支持文件夹/Multibranch 懒加载。
- **按需加载任务树**：根任务、文件夹、Multibranch 任务按层加载；任务路径按连接隔离，避免同名任务串用。
- **任务搜索**：按名称/路径在已加载的任务树和 View 任务中搜索。
- **构建参数**：按参数类型渲染字符串、布尔、选择、密码等控件；支持无参数/有参数触发；生产、第三方等高风险连接默认只读并需要二次确认，确认框包含连接、环境、任务路径和脱敏参数。
- **构建闭环**：触发后轮询队列，显示排队原因、开始构建、构建结果、耗时、控制台日志，并支持停止构建、取消排队；多个排队项可展开查看并逐项取消，页面打开时每 5 秒自动刷新队列。
- **增量日志**：运行中构建按 2 秒增量拉取日志并自动跟随，可手动刷新日志。
- **构建详情**：展示 Pipeline 阶段、构建产物和 JUnit 测试报告（插件/接口可用时），构建产物可调用系统默认程序打开。
- **收藏与最近访问**：任务可收藏，自动记录每个连接最近访问的任务。
- **完成通知**：构建完成/失败/中止时写入托盘提示，并在左侧 Jenkins 导航显示未读数量。
- **审计**：触发构建、停止构建、取消排队写入审计库。
- **多连接隔离**：每个连接独立 Cookie/CSRF/客户端和轮询，切换连接时取消旧请求；最后选择的连接按本机 UI 偏好恢复。
- **SSH 隧道**：本机不能直连 Jenkins 时，可为连接选择已配置的 SSH 服务器；使用动态 SOCKS5，保留原始 Jenkins 主机名和 HTTPS SNI，API 返回的绝对 URL 不需要改写。
- **认证**：优先使用 Jenkins API Token；连接测试会识别认证失败、HTML 登录页、CSRF 和权限不足。

## 资产拓扑（主图 + 结构化视图）

拓扑主图**只来自人工配置**：服务器、应用、数据源、域名，加上 `config.json` 中的人工关系，以及由运行环境字段推导的 `runsOn/runsIn`、由跳板/隧道配置推导的 `accessedVia`。自动发现结果只作为**发现证据、配置建议、配置体检**展示，不再生成 `*:disc:*` 待确认节点，也不写入主图。

- **旧版可视化画布（可编辑）**：服务器 / 应用 / 数据源及关系可视化（`runsOn` 内嵌、`connectsTo` / `canAccess` 避障正交连线 + 圆点 / 箭头 / 过桥）。
  - **拖动**节点（拖服务器带动其内子节点）、**缩放**节点（四角手柄 + 四边内侧直接拉伸）；
  - 从节点**边中点端口**拖到另一节点创建关系（自动推断类型并做逻辑校验）；拖动节点进出服务器会直接修改运行环境字段，而不是新增 `runsOn` 人工关系；
  - **点选连线**后右侧出现**关系属性面板**：修改**关系类型**、编辑**备注**并保存，或删除（也可按 `Delete`）；关系类型下拉已精简并显示中文：运行于服务器 / 运行于容器 / 连接到 / 可访问 / 上游依赖 / 通过跳板访问 / 相关；
  - **关系线型区分**：连接到/可访问为实线（可访问为绿色）、运行于容器为长虚线、上游依赖为中虚线、通过跳板访问为细虚线、相关为点线；由运行环境/跳板/隧道推导的连线在属性面板提示为“配置推导”，不能直接删除，需到对应资产配置中修改；
  - **无限画布**：滚轮缩放、**左键按住空白处拖动平移**、**「更多操作 ▾」**（`＋ / － / 适应 / 100%`（`Ctrl+0` 重置）/ 刷新 / **导出图片…**）；**网格吸附（10px）**；关系属性面板可拖动；
  - **节点右键 → 查看/编辑关系**：列出相关关系，可删除或编辑类型与备注；解除运行环境后相关应用 / 数据源自动挪到就近空白处；
  - **Ctrl+Z 撤销 / Ctrl+Y 重做**、**「重新自动布局」**；手动布局保存在 `%APPDATA%\LitSSH\topology-layout.json`；
  - **「更多操作 ▾ → 快照时间线…」**：按服务器回放最近 N 份快照，对比节点/关系规模及新增、移除明细，并可跳转对应快照历史；
  - **发现证据**：选中服务器后可查看最近快照中的端口、服务、容器、站点和证书证据；这些信息只用于排查与配置建议，不进入主图；Docker `runsIn` 成员在画布中以缩进方式表达两级归属；
  - **影响面高亮**：选中任一节点后按反向 incoming 边做 2 跳 BFS，高亮「谁依赖它」，其余节点/边降透明并显示影响数量。
- **新版结构化视图（只读）**：入口为画布顶部「新版拓扑」，提供 **服务器泳道 / 应用链路 / 依赖矩阵 / 配置建议** 四个标签页；支持搜索、跨服务器依赖筛选、链路多跳路径、服务器间关系数量矩阵，以及一键应用高置信度配置建议、运行配置体检。

```
app:order-service  --runsOn-->     ssh:web-server-01    # 应用运行在服务器（运行环境字段推导）
ds:mysql-order-01  --runsOn-->     ssh:db-server-01     # MySQL 运行在服务器
app:order-service  --runsIn-->     app:docker-host-01   # 应用运行在 Docker 应用
app:order-service  --connectsTo--> ds:mysql-order-01    # 应用连接数据库
ssh:web-server-01  --canAccess-->  ds:mysql-order-01    # 服务器可访问数据库
ds:mysql-order-01  --accessedVia--> ssh:jump-server-01  # 数据源通过跳板服务器访问
```

## AI 运维助手

App 内置的**大模型运维智能体**——在 App 内配置 **OpenAI 兼容大模型**（DeepSeek / 通义千问 / Kimi / 智谱 GLM / 硅基流动 / 本地 Ollama 等，可**多模型启用 / 停用**、设默认、**对话中热切换**），用自然语言对话完成服务器 / 数据源 / 应用运维。它通过**内嵌 MCP 客户端**（stdio 子进程）调用本机 MCP 服务器，即**全部 34 个默认外部工具 + 1 个宿主内部审批工具**（旧工具名已删除；另按会话启用本机终端、工作区文档、任务计划等本地工具），因此**桌面审批、命令过滤器、审计哈希链与第三方 AI 客户端完全一致**。

- **对话体验**：流式输出、**多会话管理**（新建 / 切换 / 删除、首条消息自动命名，独立 `agent.db`；点「新建任务」**不写库、首次发送消息才落库**；侧栏按**分组**归类（「未分组」置顶、分组可重命名/删除、归档恢复保留分组；支持**拖拽**会话入组/排序、分组**拖拽排序**与**折叠/展开**；右键仅作用于鼠标所在行且打开菜单时保持悬浮高亮））、**只读模式**（全局仅暴露只读工具）、**工具分组裁剪**（均在「AI 助手设置」全局配置；会话期内工具集恒定，利于 Prompt Caching）；打开 / 切换会话有**加载动画**，超长会话**转录分页懒加载**（默认渲染最近 20 轮，顶部可加载更早；会话侧栏仅加载元数据、仅重建当前会话上下文，启动裁剪后台执行）；回答以 **Markdown 渲染**，每轮按 **用户指令(带时间) → 工具过程 → 回答(带时间与耗时)** 展示（工具过程运行中展开、完成后折叠）。每轮回答下方展示**本轮关联**：自动提取工具轨迹涉及的 SSH 服务器、数据源和 `ops_doc_*` 产出文档，支持插入会话、打开终端/工作台/只读查看或打开文档。
- **本机 PowerShell 多终端（ConPTY）**：可从「SSH 会话窗口 → 新建连接 → 本机 PowerShell 终端」打开**真实本机终端**；内置助手可用 `local_shell_open` / `local_shell_manage(action=list|read)` / `local_shell_stop` 在**同一可见会话**里管理最多 4 个 `term-N` 终端，并行跑前端、后端、下载与脚本测试（共享 `cwd`/环境）。不带 `terminalId` 的 `local_shell` 使用默认共享终端；传入空闲的 `term-N` 可继续向该终端注入一次性命令，命令结束后终端仍保留；`local_shell_stop` 停止进程树并关闭对应标签。安全：**硬白名单**（仅白名单内 CLI 可执行）、危险命令拦截，`open` 与每命令仍**逐次人工审批**（可勾选放行范围：默认仅本次；「本轮次内允许全部命令（不建议）」下一条用户消息后恢复审批；「本次 AI 会话期间允许全部命令（不建议）」本会话内不再逐条确认，白名单与危险拦截仍生效；「总是允许此命令」写入配置永久记忆），`local_shell_manage` 的 `list`/`read` 只读，`local_shell_stop` 免审批但写审计；长驻命令（`tail -f`、dev server、构建、下载等）可运行，裸 shell/REPL、`Start-Process`/`Start-Job`、尾部 `&` 等后台化写法前置拒绝，超时中断 + 进程树清理。默认**关闭**，在「AI 助手设置 → 本机终端」启用并配置白名单等。**终端按 AI 会话隔离**：每个会话最多 4 个终端，标题形如 `本机 PowerShell [AI-进程Id]`；手动可开多个本机终端互不影响。
- **斜杠命令**：输入框支持 `/技能`（打开技能选择窗口，多选本会话激活的运维技能）、`/临时聊天`（独立纯聊天面板，不注入技能/工具、仅内存、可切模型、关闭即清空）、`/压缩会话`（摘要较早轮次）、`/清空屏幕`（仅清显示）、`/清空上下文`（仅重置模型上下文）；并支持**用户自定义提示词模板**（「AI 助手设置 → 提示词模板」里定义 `/命令名` → 提示词，选中后填入输入框）；面板悬浮于输入框上方，↑/↓/Enter/Tab/Esc 操作，移动时自动滚动。
- **技能与工具**：技能为**目录式**（`skills/<name>/SKILL.md`），**技能根目录默认为 `%APPDATA%\LitSSH\skills`**（**稳定目录**：跨重编译 / 升级保留，首次自动把随包 `skills/` 复制过去，用户新装的技能不再随 bin 清理丢失；「AI 助手设置 → 技能根目录」可覆盖），**其绝对路径注入系统提示**（模型安装 / 新增技能时直接落到该目录下的子目录，无需猜测路径；本会话技能索引为启动时快照，新技能**下次会话**生效）。App 随包分发**一组预置运维技能**（nginx 5xx、磁盘满、CPU/内存飙高、MySQL/Redis 排障、容器起不来、systemd 失败、证书到期、日志定位、端口占用、网络连通、发布回滚、Java GC/JVM 等）与总纲 `litssh-mcp-ops-skill`。**默认"索引模式"**（未选技能只注入技能索引，极省 token）；用 `/技能`（带预览的完整选择窗口）或输入区 `+ 菜单 → 选择技能…` 选择，也可在输入框键入 `/` **内联选择**（命令列表中直接列出技能，选中即切换激活、✓ 指示），已激活技能以 **chip** 显示、可移除，选择为**会话级并持久化**（`agent_sessions.ActiveSkills`，跨重启恢复），并支持**会话内热切换**（切换会重算技能段系统提示前缀缓存；连接器子集仍保持启动后锁定）。选择窗口支持**导入文件/目录、打开技能目录、双击用外部编辑器编辑**。技能按**当前可用能力域**裁剪（涉及域全停用则跳过、部分停用加提示）。自动注入**工作区文档工具** `ops_doc_read(action=list|read)` / `ops_doc_write(mode=overwrite|append|patch)`（维护 `OPS_ASSETS.md` 运维资产档案，按需读、增量写）与**任务计划工具** `update_plan`（顶部**任务计划面板**显示进度 ☑/☐，计划**跨重启恢复**）。
- **智能体（Agent）**：「AI 助手设置 → 智能体」内置 **通用聊天 / 运维专家 / 数据库分析** 三个预置智能体（可编辑 / 删除 / 新增；含名称、描述、**系统提示附加段**与可选**回答风格覆盖**）。**主窗口输入区**与**临时聊天**均提供**智能体下拉**（末项「智能体设置…」直达设置对应页），切换**就地热更新系统提示**（不重连 MCP、不改工具集、不丢历史；附加段位于提示词**最末尾** → 只使缓存**尾部前缀**失效）；**按会话记忆**（`agent_sessions.AgentId`，回退到全局默认 → 第一个 → 无智能体）并同步全局 `agent.activeAgentId`。系统提示同时内置**软件变更护栏**（不擅自安装 / 升级 / 卸载软件包、不改系统级配置，需先征得用户同意）。数据库工作台 **「AI 分析此 SQL」** 只预填 `sql` 代码块并自动切到「数据库分析」智能体。
- **MCP 服务器（外部接入）**：「AI 助手设置 → **MCP 服务器**」管理 AI 可用的 MCP —— **内置 LitSSH MCP 置顶、只能启停**（停用后 AI 没有本机服务器 / 数据源等运维工具，exe 路径仍在「助手设置」配置）；可**添加外部 MCP**，传输支持 **stdio**（`command` + `args` 每行一个 + `env` 每行 `KEY=VALUE`）与 **http**（SSE / Streamable HTTP，`url` + `headers` 每行 `Name: Value`），env / header 的值按当前 Windows 用户 **DPAPI 加密**落盘。**启用前必须「校验连接」通过**（完成一次 `initialize` + `tools/list`，15 秒超时，记录校验时间与工具数）；**校验失败也可保存**（保持**停用态**），内置 MCP 停用需二次确认。保存并关闭设置窗口即**重建连接**；某个外部服务器连接失败**只降级不阻断**（状态栏提示「N 个外部 MCP 未连接」，系统提示注明该服务器本次不可用及原因）。外部工具与既有工具**重名时自动加服务器前缀**（如 `` `fs_ssh_exec` → ssh_exec ``，映射写入系统提示），系统提示同时列出每个外部服务器的工具数与**安全边界**：第三方工具**不经过本程序的审批 / 命令过滤 / 审计**（只读模式仅按其自报的 `annotations.readOnlyHint` 过滤），写入 / 删除 / 发送类操作须先征得用户同意。**会话窗口快捷入口**：输入区「计划 / 执行模式」旁的**「连接器」按钮**弹出 MCP 清单（内置置顶、显示连接状态与工具数），**勾选即启用 / 停用并立即生效**（外部启用仍须校验通过、内置停用弹确认），不用绕进设置页。
- **可选长期记忆 / RAG**：配置 OpenAI 兼容 **Embeddings** 端点即可把历史会话与工作区文档向量化、按相似度**召回**注入上下文；召回使用 **FTS5/BM25 + 向量混合**，带中英文运维同义词查询改写、精确短语轻量重排，可配置独立 `memory.rerankProviderId` 重排模型，中文短词额外用子串匹配兜底；结构化记忆支持历史版本/回滚（每 MemoryId 保留最近 40 版，桌面与 Web 管理员均可操作）。
- **桌面端工作日志**：含变更操作的任务结束后，自动把「请求 → 关键操作 → 结果」追加到 `我的文档\LitSSH\worklogs\YYYY\YYYY-MM-DD.md`（按天归档、永久保留）；默认记录失败 / 被拒操作，纯只读调查可选；写入前统一脱敏密码 / 令牌，不额外调用模型。可在「AI 助手设置 → 助手设置 → 工作日志」开关、改目录或打开日志文件夹；启用后 AI 可用已有的 `ops_doc_write(mode=append, path="worklogs/YYYY/YYYY-MM-DD.md", content=...)` 追加 3-5 行复盘；系统提示给出当天路径与固定格式，不再使用专用工作日志工具。Web 端暂不记录。
- **运维视图 / 事件与知识沉淀**：桌面「助手设置 → 运维视图」与 Web 顶栏「运维视图」可查看事件列表、事件时间线（用户请求 / 工具调用与结果 / 助手结论）和资产画像（图谱邻域 / 影响面 / 历史事件 / 资产事实 / 脚本经验）；管理员另有「记忆候选」审核（事件 / 资产事实 / 脚本候选）与 consolidation 运行入口；consolidation 支持每日运行/raw 配额、可选低成本模型 `providerId`，只生成 pending 候选、人工审核后写入；失败会写 `consolidation_failed` 访问日志，Web「记忆候选」面板显示失败告警与运行历史。
- **批量变更（计划 / 预检 / 金丝雀 / 回滚）**：桌面左侧栏「批量变更」窗口支持从当前账号可见服务器清单筛选目标，按 `plan → dry_run → canary → apply → rollback` 执行，自动回填计划 ID 并展示阶段与逐台结果；计划持久化 `agent.db`（owner/会话隔离、2 小时 TTL，可从最近计划恢复），执行中可取消（不自动回滚已成功目标）、可仅重试失败目标、按目标选择性回滚、设置单台超时，MCP `ssh_execute_fleet` 通过 progress 通知上报逐台进度；Web 入口暂时隐藏（保留实现与后端链路）。
- **运行中追加指令（排队 / 插队）**：会话运行中按 `Enter` 将消息加入**当前会话队列**，当前轮成功后自动续跑；`Ctrl+Enter` 在当前轮下一处模型/工具检查点插队。队列支持附件、编辑载入输入框、置顶优先、单条移除/清空/继续；停止或失败后暂停队列，不自动继续。队列按会话隔离，持久化到本机 **DPAPI 加密**文件，切换会话/重启后恢复为暂停状态；后台会话完成任务后也会继续自己的队列。
- **工作目录入口**：AI 侧栏「打开工作目录」固定打开共享工作区根目录（不随会话切换）；会话行右键「打开会话工作目录」打开该会话的独立目录。
- **稳定性与成本**：每模型可配**超时 / 重试 / 并发**并对失败给出**分类提示**；系统提示内置**提示注入防护**；**技能按需加载**、**工具描述精简**、**快照默认返回概览**、**大结果落盘句柄**（`spill(action="read"|"grep", handle=...)`）与**子代理隔离**（`run_subagent` 只回摘要；轮数/超时/摘要上限可配，复杂只读取证提前委派）；同一轮**只读工具并行执行**、**连续失败熔断**、日志类结果保留最新尾部；系统提示 / 工具定义为**稳定前缀**并显示**缓存命中率**；工具轨迹与滚动摘要**落库、重启可恢复**；**冷启动只向模型注入最近 N 轮**（`agent.coldStartRecentTurns`，更早由滚动摘要代表，降低首次请求开销）；**回答风格**可选 `concise`(默认) / `standard` / `detailed`；`+ 菜单 → 用量 / 成本…` 展示当前会话的请求次数、输入/输出/缓存命中 token 与**估算成本**（模型价格在「大模型设置」按每百万 token 填写）。
- **安全**：模型 API Key 本机 **DPAPI 加密**存储；破坏性工具调用会提示"可能等待人工审批"。
- **桌面登录（可选，仅归因）**：AI 助手窗口侧栏显示「归因：未登录（local）」/「归因：<用户名>」并可**登录 / 注销**——账号与 Web 助手共用 `web.db`（失败计数与锁定曲线同样共享，防绕过限速），登录态经 **DPAPI 加密落盘、跨重启保持**；登录后**新会话** owner 与审计 UserId 记为该用户（会话目录归到其用户名下），未登录继续归因 `local`；桌面**不做权限限制**（评估报告 D1「仅归因不限权」）。
- **计划模式与工具级策略**：输入区（上下文环左侧）**模式下拉（执行模式 / 计划模式）**——计划模式**不改系统提示/工具集**（缓存友好），每轮附提示并在调用前拦截写工具：模型只做只读调研、列计划不擅自执行；切回执行模式后由你自行发指令（会话级持久化）。`+ 菜单 → 工具审批策略…` 可按工具设置 **默认/允许/拒绝**（拒绝=调用前拦截；允许不绕过服务端桌面审批）。「AI 助手设置 → 助手设置 → 会话工具模式」可直接选择 `auto/diagnose/change/assets/chat`，新会话生效；设置页会根据最近会话首个用户诉求给出建议，可一键采用（不静默切换）。

> 首次使用请在助手的「AI 助手设置」中添加并启用模型（发布包已内置 MCP 服务器 exe：`mcp/LitSSHmcp.McpServer.exe`）。
