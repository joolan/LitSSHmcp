# 快速上手

> 本文档是应用内使用说明的唯一事实来源；功能变化时请同步更新本文件。

1. 打开「服务器」页面，点击「添加」，填写主机、端口、账号和认证方式。
2. 双击服务器行打开终端；右键可以打开 SFTP、端口转发、资源监控等工具。
3. 在「数据源」页面添加 MySQL / PostgreSQL / Redis 连接，双击打开数据库工作台。
4. 在「应用」和「远程桌面」页面维护资产，供拓扑和 AI 运维助手使用。
5. 打开「AI 运维助手」，先配置模型，再通过自然语言查询状态、排查问题或执行运维操作。
6. 在「审计」页面查看命令、SQL 和会话记录，并校验哈希链完整性。

# 功能说明

## 资产与连接

- SSH 服务器：终端、SFTP、端口转发、资源监控、快照、批量执行。
- 数据源：MySQL、PostgreSQL、Redis，只读工作台与 SQL 查询。
- 应用：配置运行环境（SSH 服务器 / Docker 应用 / 独立环境）、Docker 容器或 Compose service、AssetKey、别名，以及多条 URL 访问入口（URL / 角色 / 优先级 / 备注）；同一 URL 多后端视为负载均衡。
- 远程桌面：RDP / VNC，支持通过 SSH 隧道访问内网桌面。

## 资产拓扑

- 旧版拓扑画布可拖动/缩放节点、拖线建立关系、编辑关系类型与备注；关系类型下拉显示中文。
- 拖动应用或数据源进出服务器会修改运行环境字段，并据此推导 `runsOn/runsIn`；服务器与 Docker 应用两级嵌套以缩进展示。
- 主图只来自人工配置（服务器 / 应用 / 数据源 / 域名 + 人工关系 + 运行环境推导）。自动发现只提供发现证据、配置建议和配置体检，不生成待确认节点。
- 新版拓扑为只读结构化视图，含服务器泳道、应用链路、依赖矩阵、配置建议；可应用高置信度建议并运行配置体检。
- 服务器发现证据可查看最近快照中的端口、服务、容器、站点和证书信息，但不会写入主图。

## 会话与任务

- 同一服务器最多打开 4 个终端。
- 会话管理窗口支持标签、平铺布局、分离窗口和批量执行。
- 同步任务、触发事件和端口转发在独立窗口中管理。
- 关闭主窗口时可以选择最小化到托盘，后台会话和 AI 任务继续运行。

## AI 运维助手

- 支持多会话、执行模式和工具过程展示。
- AI 调用工具前仍受安全策略、审批和审计约束。
- 可在主界面 AI 页面或独立窗口中运行。
- 切换会话不会停止后台任务。
- 工作日志（桌面端）：含变更操作的任务结束后自动追加到共享工作区 `worklogs\年\年-月-日.md`，按天归档、永久保留；默认记录失败 / 被拒操作，写入前脱敏。可在「AI 助手设置 → 助手设置 → 工作日志」开关或打开目录；Web 端暂不记录。
- 工作目录入口：AI 侧栏「打开工作目录」打开共享工作区根目录（不随会话切换）；会话行右键「打开会话工作目录」打开该会话的独立目录。
- 技能：输入 `/技能` 或输入区 `+ → 选择技能…` 打开技能选择窗口；技能可在当前会话内热切换（会重算技能段系统提示前缀缓存），连接器子集仍在首条消息后锁定。
- 子代理：可在「AI 助手设置 → 子代理」配置最大轮数、超时与摘要上限；子代理只做隔离的只读调查并把摘要返回主会话，大输出按落盘句柄分段读取。
- Web 会话同步：桌面仅在 AI 页面可见、且没有本地会话运行/编辑时对账 `agent.db`；有变化时 5s、空闲 20s，页面重新可见立即补一次。

## 审计与安全

- 审计记录包含命令、SQL、会话、审批决策和退出码。
- 支持导出 CSV 和校验哈希链完整性。
- 高危命令、只读数据源、工具审批策略均可在设置中配置。

# Web 端

Web 端是基于浏览器的 AI 运维助手，和桌面 App、MCP 服务共用同一套配置与安全策略。

## 启动

```bash
dotnet run --project src/LitSSHmcp.Web
# 默认访问 http://localhost:5000
```

发布版可执行文件位于 `publish-web`。默认只监听本机；需要跨机访问时，应由管理员显式配置监听地址，并优先使用 HTTPS，避免在公网直接暴露明文 HTTP。

## 访问与安全

- 默认地址为 `http://localhost:5000`
- 跨机访问需要显式配置监听地址，并建议配置 `web.https` 证书
- 反向代理场景应配置 `web.trustedProxies`，避免伪造来源 IP
- Web 登录、会话和审批都受账号、角色、限流和审计约束
- 不要直接暴露到公网；需要远程访问时优先使用内网、VPN 或 HTTPS 反向代理

## 账号与权限

- 使用独立账号库 `web.db`，没有内置默认账号
- 首个创建账号自动为 `admin`，之后默认创建普通 `user`
- 管理员可以查看全部用户的历史和会话，普通用户只能访问自己的数据
- 登录失败会触发限流和锁定策略
- 桌面 App 的「桌面登录」与 Web 账号是两个独立体系

## 常见操作

1. 启动 Web 服务，并用命令行创建第一个管理员账号。
2. 浏览器打开地址并登录。
3. 选择模型和智能体，创建或打开一个会话。
4. 发起运维问题，等待流式回复和工具审批。
5. 在审批面板处理待审批操作，或停止当前任务。
6. 配置类修改回到桌面 App 完成，新会话生效。

## 功能

- 浏览器内流式 AI 对话、工具调用过程和审批
- 多会话、会话级模型切换、图片附件
- 服务器目录浏览与文件下载
- 会话删除、停止和后台执行
- Web 审批卡片与待审批提醒
- 响应式布局，支持桌面和手机浏览器
- Markdown 表格、任务列表、代码块和工具轨迹折叠

## 限制

- Web 端不包含本机终端工具
- Web 端不提供配置写入口，服务器、数据源、模型等配置仍在桌面 App 修改
- 配置修改对新会话生效；安全策略按配置热加载
- Web 会话运行在独立子进程中，删除会话会终止对应进程
- 历史分页懒加载，首屏最多显示最近 120 轮

# 安全与审批

- 保存的凭据仅在本机加密存储。
- 命令过滤、只读模式、写操作审批和审计共同构成安全边界。
- 不同 AI 客户端调用同一 MCP 服务时，都会经过相同的安全策略。
- 临时 SSH 连接只保存在内存中，关闭会话即释放；仍保留主机密钥校验。
- 桌面登录只用于审计归因，不改变工具权限。
