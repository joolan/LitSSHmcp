# 桌面宠物示例素材包

这里提供可直接导入 LitSSH 的桌面宠物素材包。下载 ZIP 后，在应用内通过“设置 → 桌面宠物 → 导入 ZIP…”使用，不需要解压。

## 素材包列表

| 文件 | 名称 | 风格 | 动作 | 大小 | 许可证 |
|------|------|------|------|------|--------|
| [clay-cat-1.0.zip](./clay-cat-1.0.zip) | 桃桃 · 黏土粉猫 | 黏土 / 3D 矢量感 | 全套 8 动作 | 约 1.6 MB | CC0-1.0 |
| [ops-pet-1.0.zip](./ops-pet-1.0.zip) | 小机 · 运维桌宠 | 程序化矢量 | 全套 8 动作 | 约 508 KB | CC0-1.0 |
| [ops-pet-2.0.zip](./ops-pet-2.0.zip) | 小机 · 运维桌宠2 | 程序化矢量 | 全套 8 动作 | 约 706 KB | CC0-1.0 |
| [pixel-cat-1.0.zip](./pixel-cat-1.0.zip) | 桃桃 · 像素猫 | 像素点阵 | 全套 8 动作 | 约 101 KB | CC0-1.0 |

所有示例均包含：

- `idle`
- `walk`
- `drag`
- `click`
- `sleep`
- `stretch`
- `look`
- `work`

默认素材格式版本为 `1`，默认帧率约 `10 FPS`，动作帧使用透明背景。

## 使用方式

1. 打开 LitSSH。
2. 进入“设置” → “桌面宠物”。
3. 点击“导入 ZIP…”。
4. 选择本目录下的 ZIP。
5. 在素材列表中选择新素材。
6. 点击“保存并应用”。

## 来源与许可

这些素材包均为项目示例素材，许可证为 **CC0-1.0**。每个 ZIP 内包含：

- `SOURCE.txt`：来源与生成方式
- `LICENSE.txt`：许可证文本
- `pet.json`：素材包元数据与动作定义

来源概要：

- `clay-cat-1.0.zip`：AI 文生图（形象）+ 程序化帧动画。
- `ops-pet-1.0.zip` / `ops-pet-2.0.zip`：本地原创，程序化矢量绘制，AI 辅助生成。
- `pixel-cat-1.0.zip`：本地原创，像素点阵绘制，AI 辅助生成。

## 说明

- 这些是示例素材，不随 App 安装包内置。
- 内置的 `builtin` 占位宠物由程序生成，不需要下载。
- 自定义素材会保存在 `%APPDATA%\LitSSH\pet-assets`。
- 可以在“设置 → 存储维护 → 定时备份”中勾选“桌面宠物素材”进行备份。
